# Voyage X – Project Abstract

## Introduction
Voyage X is a smart travel booking application developed using Flutter and Dart. It aims to make travel planning easier through a simple and user-friendly interface.

## Problem Statement
Planning a journey can involve checking different travel options and comparing prices. VoyageX aims to organize this process in one application.

## Objectives
- Simplify travel planning.
- Allow users to enter source and destination.
- Display travel options and prices.
- Collect passenger details.
- Show booking confirmation.

## Proposed Screens
1. Home Screen
2. Search Results Screen
3. Booking Screen
4. Ticket Confirmation Screen

## Technologies
- Flutter
- Dart
- Git
- GitHub

## Scope
The project focuses on transportation booking, including bus, train, and flight options. Hotel booking is outside the project's scope.

## Conclusion
Voyage X demonstrates mobile application development using Flutter, including user interface design, navigation, forms, and booking confirmation.
